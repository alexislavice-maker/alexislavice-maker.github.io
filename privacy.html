Privacy policy

Last updated: November 9, 2026

Hermes is a self-hosted personal assistant used exclusively by its owner, Alexis Lavice. It is not distributed to, nor used by, any other person.

Data accessed

With the account holder's explicit OAuth consent, Hermes accesses Google user data (Gmail, Google Drive, Google Calendar, Google Docs, Google Sheets, Google Contacts) of a single account controlled by the owner, solely to perform tasks the owner requests.

Storage and sharing

  • OAuth tokens and any retrieved data are stored only on the owner's private server, with restricted file permissions.
  • Google user data is not sold, not used for advertising, and not shared with third parties.
  • Google user data is not used to train generalized AI or machine-learning models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation

Access can be revoked at any time at myaccount.google.com/permissions, after which locally stored tokens are deleted.
